**Version:** 2.0  
**Status:** Draft

---

# 1. Vision

Knowledge Factory is a standalone educational knowledge engineering platform that transforms educational content into a structured, AI-ready knowledge base.

Its purpose is **not simply to extract text from documents**, but to convert educational material into reusable teaching knowledge that can power intelligent tutoring systems such as **MathVerse AI Tutor**.

Knowledge Factory is designed as a provider-independent, modular platform capable of processing educational content from multiple sources while producing a single canonical knowledge model.

---

# 2. Why Knowledge Factory Exists

Traditional OCR systems extract text.

Traditional document processing systems produce searchable documents.

Knowledge Factory goes beyond document extraction by producing structured educational knowledge.

Instead of asking:

> "What text is inside this PDF?"

Knowledge Factory answers:

> "What knowledge does an AI teacher need in order to teach this topic?"

This distinction drives every architectural decision in this project.

---

# 3. Mission

Create the world's most comprehensive educational knowledge platform capable of transforming textbooks and educational resources into structured knowledge that AI tutors can teach naturally.

Knowledge Factory is responsible for producing:

- Educational knowledge
- Teaching knowledge
- Curriculum knowledge
- Assessment knowledge
- Relationship knowledge

It is **not** responsible for tutoring students.

---

# 4. Relationship with MathVerse

Knowledge Factory and MathVerse are independent products.

## Knowledge Factory Responsibilities

Knowledge Factory is responsible for:

- Document ingestion
- OCR integration
- Canonical document generation
- Educational knowledge extraction
- Knowledge graph generation
- Semantic chunk generation
- Embedding generation
- Metadata management
- Knowledge storage

Knowledge Factory never teaches students.

---

## MathVerse Responsibilities

MathVerse consumes the knowledge generated by Knowledge Factory.

MathVerse is responsible for:

- AI tutoring
- Voice conversations
- Whiteboard teaching
- Diagram explanation
- Image question solving
- Mock tests
- Adaptive learning
- Student progress tracking
- Personalization

MathVerse never extracts knowledge directly from educational documents.

---

# 5. Guiding Principles

Knowledge Factory is built on the following principles.

## 5.1 Provider Independent

The system must never depend on a single OCR or AI provider.

Examples include:

- Google Document AI
- Azure Document Intelligence
- AWS Textract
- Open Source OCR

The output must always conform to the canonical knowledge model.

---

## 5.2 Canonical First

Every ingestion pipeline must produce the same canonical knowledge representation regardless of the source technology.

No downstream service should understand provider-specific formats.

---

## 5.3 Educational First

The primary output is educational knowledge rather than document content.

Examples include:

- Concepts
- Definitions
- Formulae
- Theorems
- Proofs
- Derivations
- Examples
- Exercises
- Figures
- Relationships

---

## 5.4 Modular Architecture

Every stage of the pipeline must have a single responsibility.

Example:

PDF Ingestion

↓

Document Processing

↓

Canonical Document

↓

Knowledge Extraction

↓

Knowledge Graph

↓

Semantic Chunking

↓

Embeddings

↓

Storage

---

## 5.5 Deterministic Core

The ingestion pipeline should remain deterministic wherever possible.

Artificial Intelligence should be introduced only where semantic understanding provides clear value.

- CBSE curriculum
- ICSE curriculum
- State boards
- JEE Main
- JEE Advanced
- NEET
- Teacher notes
- Coaching material
- Previous year papers
- Sample papers
- Revision notes

without requiring architectural changes.

---

# 7. Success Criteria

Knowledge Factory is successful when:

- Any supported educational document can be transformed into the canonical knowledge model.
- Multiple AI tutors can consume the same knowledge.
- The platform remains independent of OCR vendors.
- Educational knowledge can be reused across products.
- New educational sources can be added without redesigning the architecture.

---

# 8. Scope

Knowledge Factory includes:

- Knowledge ingestion
- Knowledge extraction
- Knowledge modeling
- Knowledge validation
- Knowledge storage
- Knowledge APIs

Knowledge Factory excludes:

- Student chat
- Voice tutoring
- Whiteboard interaction
- Mock testing
- Personalized tutoring
- Student memory
- Progress tracking

These belong to MathVerse.

---

# 9. Future Vision

Knowledge Factory is intended to become the educational knowledge platform powering multiple AI educational products beyond MathVerse.

Its outputs should be reusable by:

- AI Tutors
- Teacher Assistants
- Learning Analytics
- Curriculum Management Systems
- Assessment Platforms
- Educational Search Engines
- Knowledge Graph Applications
