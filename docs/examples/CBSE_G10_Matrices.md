# 2. Chapter Overview

## Educational Purpose

This chapter introduces students to matrices as rectangular arrangements of numbers, variables, or expressions. It teaches how matrices are represented, classified, compared, and manipulated through mathematical operations. The chapter progresses from basic concepts to operations such as addition, subtraction, scalar multiplication, and matrix multiplication, followed by worked examples and exercises. :contentReference[oaicite:0]{index=0}

## Why this chapter matters

This chapter lays the foundation for later mathematical topics and develops structured problem-solving skills using matrix operations.

## 7. Definitions

### 7.1 Matrix

A matrix is a rectangular arrangement of numbers, symbols, or algebraic expressions arranged in rows and columns and enclosed within brackets.

**Purpose**

Represents mathematical data in a compact form for performing algebraic operations.

---

### 7.2 Row Matrix

A matrix having only one row.

---

### 7.3 Column Matrix

A matrix having only one column.

---

### 7.4 Rectangular Matrix

A matrix in which the number of rows is not equal to the number of columns.

---

### 7.5 Square Matrix

A matrix having the same number of rows and columns.

---

### 7.6 Zero Matrix (Null Matrix)

A matrix in which every element is zero.

---

### 7.7 Diagonal Matrix

A square matrix in which all non-diagonal elements are zero.

---

### 7.8 Scalar Matrix

A diagonal matrix in which all principal diagonal elements are equal.

---

### 7.9 Identity Matrix (Unit Matrix)

A scalar matrix whose principal diagonal elements are all equal to one.

---

### 7.10 Equality of Matrices

Two matrices are equal if:

- They have the same order.
- Every corresponding element is equal.

---

## 8. Formula Library

### 8.1 Matrix Addition

**Formula**

If

A = [aᵢⱼ]

and

B = [bᵢⱼ]

are matrices of the same order, then

A + B = [aᵢⱼ + bᵢⱼ]

**Condition**

Both matrices must have the same order.

---

### 8.2 Matrix Subtraction

**Formula**

A − B = [aᵢⱼ − bᵢⱼ]

**Condition**

Both matrices must have the same order.

---

### 8.3 Scalar Multiplication

**Formula**

kA = [k × aᵢⱼ]

where k is a scalar.

---

### 8.4 Matrix Multiplication

**Formula**

If

A is of order m × n

and

B is of order n × p

then

AB is of order m × p

Each element of AB is obtained by multiplying corresponding row and column elements and taking their sum.

---

### 8.5 Condition for Matrix Multiplication

Matrix multiplication is defined only when

**Number of columns of the first matrix = Number of rows of the second matrix**

---

## 9. Properties

### 9.1 Matrix Addition

- Commutative Property

  A + B = B + A

- Associative Property

  (A + B) + C = A + (B + C)

- Additive Identity

  A + O = A

- Additive Inverse

  A + (−A) = O

---

### 9.2 Scalar Multiplication

- k(A + B) = kA + kB

- (k + l)A = kA + lA

- k(lA) = (kl)A

---

### 9.3 Matrix Multiplication

- Associative

  (AB)C = A(BC)

- Distributive over Addition

  A(B + C) = AB + AC

  (A + B)C = AC + BC

- Identity Property

  AI = IA = A

- Generally Not Commutative

  AB ≠ BA

---

### 9.4 Important Notes

- Matrix addition requires matrices of the same order.

- Matrix subtraction requires matrices of the same order.

- Matrix multiplication does not require matrices of the same order.

- Matrix multiplication is possible only when the number of columns of the first matrix equals the number of rows of the second matrix.

- Even if both AB and BA exist, they are generally not equal.
